# LifePath: 인생 경로 내비게이션

## 프로젝트 개요
목표 설정 및 달성 경로를 시각화하는 AI 기반 인생 설계 도구

---

## 전체 아이디어 (39개)

### 필수 (Must) 15개

#### A. 목표 설정
- **A1** 직접 목표 입력 → 자유 텍스트 입력
- **A2** 랜덤 목표 생성 → 🎲 버튼으로 프리셋 랜덤 선택 → 입력란 자동 채움 → 경로 자동 생성

#### B. 경로 생성 AI
- **B1** 3가지 경로 분기 → Fast Track / Deep Dive / Risk Path
- **B2** 합류점 (Merge Point) → 서로 다른 경로가 재합류, "어떤 길이든 도달 가능"
- **B3** 역방향 플래닝 → 목표에서 현재로 역추적, Gemini 역순 단계 분해
- **B5** 조건부 분기 → "만약 이 자격증을 취득하면" 같은 조건 기반 추가 분기

#### C. 시각화 & 인터랙션
- **C1** 상향식 나무 인터페이스 → 밑바닥(현재) → 꼭대기(목표) 수직 방향
- **C2** 경로 생성 애니메이션 → 나무 자라나듯 노드 순차 생성
- **C3** 타임라인 슬라이더 → 1/3/5년 시간축 드래그, 나무 성장 효과
- **C4** 노드 클릭 상세 정보 → 설명/필요 스킬/예상 기간 팝업
- **C5** 분기점 인터랙티브 선택 → 분기점에서 직접 경로 선택, 실시간 미래 지도 변화
- **C9** 마인드맵 노드 확장 → 노드 클릭 시 마인드맵처럼 새로운 방향의 분기 경로를 실시간 또는 사전 생성하여 표시

#### F. AI 고급 기능
- **F1** 시간의 가격표 (기회비용) → 노드별 소요 시간 + 기회비용 표시
- **F4** 경로 성공 확률 → 경로별 예상 난이도/성공 확률 AI 추정

#### H. 데이터 & 저장
- **H5** 캘린더 연동 → 구글 캘린더 등에 각 노드(마일스톤)의 예상 일정 자동 등록

### 선택 (Nice-to-have) 24개

#### A. 목표 설정 (3개)
- **A3** 대화형 목표 탐색 → Gemini 3~5턴 양자택일 대화 → 맞춤 목표 카드 2-3장
- **A4** 목표 카테고리 브라우징 → 커리어/건강/재무/관계/취미 카테고리별 탐색
- **A5** 트렌딩 목표 피드 → 다른 사용자 인기 목표 표시

#### B. 경로 생성 AI (2개)
- **B4** 경로 커스터마이징 → 노드 직접 편집/추가/삭제
- **B6** 경로 재생성 → 마음에 안 드는 경로 개별 재생성

#### C. 시각화 & 인터랙션 (3개)

- **C7** 미니맵 → 전체 경로 축소 미리보기

#### D. 게이미피케이션 (5개)
- **D1** 성취의 정원 → 완료 노드마다 잎사귀/꽃/빛 시각 보상
- **D2** 이벤트 카드 시스템 → 랜덤 이벤트(기회/장애물/지름길), Gemini 맥락 기반 생성
- **D3** 진행률 표시 → 퍼센트/프로그레스바
- **D4** 마일스톤 축하 → 주요 단계 완료 시 축하 애니메이션
- **D5** 스트릭 시스템 → 매일 접속/진행 시 연속 기록, 나무 무성해지는 보상

#### E. 소셜 & 커뮤니티 (4개)
- **E1** 고스트 모드 → 타인 선택 비중 데이터 (분기점별 선택 비율)
- **E2** 군중의 지혜 → 선택 비중 + 익명 성공 사례 스토리 공유
- **E3** 경로 공유 → 링크/이미지로 공유
- **E4** 멘토 연결 → 같은 경로 완주 사용자와 매칭

#### F. AI 고급 기능 (3개)

- **F3** 상황 맥락 반영 → 현재 스킬/경력/나이 입력 시 경로 개인화
- **F5** 주간/월간 리포트 → 진행 상황 분석 인사이트

#### G. UX & 접근성 (5개)

- **G2** 다국어 지원 → Gemini 다국어 활용
- **G3** 모바일 반응형
- **G4** 다크 모드
- **G5** 접근성 최적화 → 스크린리더, 키보드 네비게이션, 고대비

#### H. 데이터 & 저장 (4개)
- **H1** 경로 저장 → 나중에 다시 열기
- **H2** 다중 목표 관리 → 여러 목표 경로 동시 관리
- **H3** 진행 상태 체크 → 완료/미완료 노드 체크

## 아이디어 뱅크 추가 제안

### 기존 기능 임팩트 강화

- **"평행우주 비교" 모드**: 목표를 입력하면 3경로가 아니라, "3년 전에 시작했다면" vs "지금 시작하면" vs "3년 후에 시작하면"의 시간 축 비교를 보여주는 모드. 시간의 가치를 체감시켜 행동을 촉구하는 강력한 동기 부여 도구가 됨.

- **합류점 "다시 만나는 순간" 감성 메시지**: 합류점 도달 시 Gemini가 해당 경로 조합에 맞는 감성적 한 줄 메시지를 생성. 예: "돌아가도 괜찮아요, 결국 여기서 만나니까요." 데모에서 감동 극대화.

- **"첫 걸음" 하이라이트**: 경로 생성 후 각 경로의 첫 번째 노드를 특별히 강조하고, "오늘 당장 유효한 액션"이라는 라벨 부여. 실행력을 높이는 넛지로, 심사위원에게 실질적 사회 임팩트를 어필.

### 데모 와우 효과

- **음성 입력 목표 설정**: Gemini의 멀티모달 기능을 활용해 마이크 버튼으로 목표를 말하면 텍스트 변환 후 경로 생성. 라이브 데모에서 "풀스택 개발자가 되고 싶어요"라고 말하는 장면은 강렬한 인상을 남김.

- **실시간 "나무 성장" 사운드 디자인**: 경로가 그려질 때 작은 자연음(새소리, 바람)이 함께 재생. 시각 + 청각 자극으로 데모 몰입도를 크게 높일 수 있음. 구현은 간단한 Audio API 몇 줄로 가능.

- **"인생 요약" 카드 생성**: 경로 탐색 완료 후 Gemini가 선택한 경로를 기반으로 SNS 공유용 카드 이미지(html2canvas)를 자동 생성. "나의 LifePath"라는 제목과 함께 경로 요약이 담긴 카드. 적은 노력으로 바이럴 효과.

### 해커톤 차별화 포인트

- **"What If" 시나리오 버튼**: 경로 맵 위 아무 노드에서 "만약 여기서 포기하면?"을 누르면 Gemini가 즉석에서 대안 경로를 생성. 인생에 막다른 길은 없다는 메시지를 기술적으로 구현한 것으로, 심사위원에게 깊은 인상.

- **세대별 경로 프리셋**: 랜덤 목표에 "Z세대 인기 목표", "30대 전환기 목표", "시니어 도전 목표" 같은 세대별 카테고리 추가. 사회적 임팩트 주제에서 "모든 세대를 위한 도구"라는 포지셔닝 강화.

- **Gemini 실시간 응원 코치**: 노드를 클릭할 때 Gemini가 해당 단계에 맞는 응원 메시지를 한 줄 생성. "이 단계가 가장 어렵지만, 여기를 지나면 속도가 붙어요." 감성적 연결로 단순 정보 도구를 넘어 "동반자" 느낌 부여.
