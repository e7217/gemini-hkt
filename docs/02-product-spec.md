## 유저 페르소나

### Primary: "방향 탐색형" - 김서연 (24세, 졸업 예정)
- **상황**: 취업/대학원/창업 사이 고민
- **페인포인트**: 선택지 많을수록 결정 장애
- **니즈**: 각 선택지의 구체적 경로와 예상 결과 미리 보기
- **동기**: 불확실성 해소, "어떤 선택도 괜찮다" 안심감

### Secondary: "목표 실행형" - 이준호 (29세, 직장인 3년차)
- **상황**: 이직/자기개발 목표는 있으나 실행 계획 막막
- **페인포인트**: 어떻게 시작할지, 얼마나 걸릴지 감 없음
- **니즈**: 현실적 로드맵, 단계별 체크포인트
- **동기**: 실행 가능한 구체적 계획

## 유저 플로우

```
[STEP 1] 목표 입력
  ├─ A) 직접 입력: 텍스트 필드
  └─ B) 🎲 랜덤 버튼 → 프리셋 선택 → 자동 채움 → 즉시 생성
         ↓
[STEP 2] 경로 맵 (핵심 화면)
  ├─ 수직 맵 3경로 표시 (Fast/Deep/Risk)
  ├─ ◆ 합류점 시각 표시
  ├─ 노드 클릭 → 사이드 패널 상세
  └─ 🕐 타임라인 슬라이더 (1년/3년/5년)
         ↓
[STEP 3] 결과 요약 (경로 맵 내 패널)
  └─ 선택 경로 요약 + 첫 액션 아이템
```

## 아이디어 뱅크 추가 제안

### 유저 플로우 강화

- **"30초 온보딩" 스플래시**: 첫 화면에서 3초 애니메이션으로 "목표 입력 -> 나무 성장 -> 합류점 빛남"을 미리 보여주는 티저. 사용자가 무엇을 기대할 수 있는지 즉시 이해시킴. Lottie 하나로 구현 가능.

- **페르소나 기반 프리셋 강화**: "김서연처럼 시작하기" / "이준호처럼 시작하기" 버튼을 랜덤 버튼 옆에 배치. 유저 페르소나를 실제 UX에 녹여서 공감대 형성. 각 버튼 클릭 시 해당 페르소나의 고민이 자동 입력됨.

### Gemini API 활용 극대화

- **목표 자동 구체화 (Goal Refinement)**: 사용자가 "행복해지고 싶어"처럼 모호한 목표를 입력하면, Gemini가 "구체적으로 어떤 행복인가요?"라는 1회 추가 질문으로 목표를 정제. 기존 자유 텍스트 입력의 품질을 크게 높이면서 Gemini 활용도도 증가.

- **경로 간 "트레이드오프" 분석**: 3경로 생성 시 각 경로의 핵심 트레이드오프를 Gemini가 한 줄씩 요약. 예: Fast Track - "빠르지만 기초가 얕을 수 있음". 의사결정 지원 도구로서의 가치를 명확히 드러냄.

- **"경로 한 줄 요약" 자동 생성**: 각 경로를 한 줄로 요약하는 캐치프레이즈를 Gemini가 생성. 예: Fast Track - "6개월 안에 첫 이직을 성공시키는 스프린트". 경로 선택의 직관성을 높임.

### 차별화 포인트 확장

- **"실패해도 괜찮아" 복구 경로**: 특정 노드에서 실패/중단 시 Gemini가 "여기서 다시 시작할 수 있는 방법"을 제시하는 복구 경로 기능. 핵심 메시지 "잘못된 선택은 없다"를 기술적으로 완성하는 기능.

- **감정 온도계**: 경로의 각 구간에 예상 감정 상태(스트레스/성취감/불안)를 시각적으로 표시. Gemini가 각 단계의 감정적 난이도를 분석. 다른 경로 시각화 도구에 없는 독특한 감성 레이어.

- **"나만의 경로명" 생성**: 3경로에 Fast/Deep/Risk 대신 Gemini가 목표에 맞는 창의적 이름을 부여. 예: "프리랜서 되기" 목표 시 "번개 독립러", "장인의 길", "모험가의 도전". 개인화 느낌 극대화.
