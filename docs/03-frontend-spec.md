## 아이디어 뱅크 추가 제안

### 시각적 임팩트 강화 (적은 노력, 큰 효과)

- **경로 생성 시 "타이핑" 효과**: 노드가 생성될 때 제목이 한 글자씩 타이핑되는 애니메이션. CSS `@keyframes` + `steps()` 함수로 10줄 이내 구현 가능. 정적 텍스트 대비 생동감이 크게 높아짐.

- **합류점 "파문" 효과**: 합류점 노드에 물결이 퍼져나가는 CSS 리플 애니메이션. `@keyframes ripple`로 2~3개 원이 동심원으로 퍼짐. 합류의 감동적 순간을 시각적으로 강조.

- **경로 선택 시 "나머지 경로 서서히 사라짐" 효과**: 하나의 경로를 클릭하면 나머지 경로가 opacity 0.15로 서서히 페이드되면서 선택 경로만 빛나는 효과. 기존 D-2(트랙 선택 하이라이트)에 CSS transition만 추가하면 됨.

### 인터랙션 아이디어

- **노드 "롱프레스" 퀵 프리뷰**: 모바일 감성으로, 노드를 길게 누르면 작은 플로팅 카드로 핵심 정보(제목+기간+난이도)가 뜸. 사이드 패널을 열지 않고도 빠르게 훑어볼 수 있음. `onMouseDown` 타이머로 간단 구현.

- **"경로 따라가기" 자동 스크롤**: 경로를 선택하면 시작 노드부터 목표 노드까지 카메라가 자동으로 천천히 따라 올라가는 기능. React Flow의 `setCenter`/`fitBounds`를 타이머로 순차 호출. 데모에서 "나무를 따라 올라가는" 체험 제공.

- **키보드 숏컷 네비게이션**: `1`, `2`, `3` 키로 Fast/Deep/Risk 경로 전환, `↑`/`↓`로 노드 간 이동. 데모 시 마우스 없이 키보드만으로 빠르게 전환하면 전문성 어필.

### 데모 최적화

- **"스켈레톤 로딩" 맵**: Gemini 응답 대기 중 React Flow 캔버스에 회색 스켈레톤 노드들이 미리 배치되어 있다가, 실제 데이터가 오면 하나씩 색이 채워지는 효과. 로딩 시간이 오히려 연출의 일부가 됨.

- **목표 입력 필드 "플레이스홀더 롤링"**: 입력 필드의 placeholder가 3초마다 바뀌면서 다양한 목표 예시를 보여줌. "풀스택 개발자 되기...", "카페 창업하기...", "유튜버 도전하기...". `setInterval` + 페이드 전환으로 구현. 빈 화면의 지루함을 없애고 영감 제공.

- **"다크 우주" 배경 테마**: 기본 다크 모드에 미세한 별 반짝임 파티클을 배경에 추가. CSS로 50개 정도의 작은 점을 랜덤 위치에 깜빡이게 하면 "우주에서 나의 길을 찾는" 세계관 강화. 데모 스크린샷/영상의 비주얼 퀄리티가 크게 올라감.
