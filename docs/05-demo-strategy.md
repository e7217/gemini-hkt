# LifePath 데모 전략 & 구현 우선순위

## 해커톤 조건
- 시간: 약 6시간
- 주제: 사회에 임팩트를 줄 수 있는 자유 주제
- 필수: Gemini API 활용
- API 키: 확보 완료

---

## 기능 임팩트 평가 (4 Tier)

### Tier 1: 데모 필수 (없으면 데모 불가)
- 목표 입력 ★★★
- Gemini 3경로 생성 (Fast/Deep/Risk) ★★★★★
- 수직형 인터랙티브 맵 ★★★★★
- 노드 클릭 상세 정보 ★★★★

### Tier 2: 차별화 요소 (임팩트 극대화)
- 합류점 (Merge Point) ★★★★★
  - "어떤 길이든 괜찮다" 핵심 메시지
- 경로 생성 애니메이션 ★★★★
  - 정적 vs 동적 임팩트 큼
- 랜덤 목표 생성 ★★★
  - 데모 오프닝 매끄럽게
- 타임라인 슬라이더 ★★★★
  - 경량 버전(버튼)으로도 효과 전달 가능

### Tier 3: 완성도 증명
- 성취의 정원 ★★★
- 경로별 난이도/기간 표시 ★★★
- 노드 상세 팝업 ★★★
- 로컬 스토리지 저장 ★★

### Tier 4: 비전 (구현 생략 가능, 발표에서 언급)
- 고스트 모드 ★★★★
- 이벤트 카드 ★★★
- 역방향 플래닝 ★★★★
- 편향 탐지 ★★★★
- 멘토 매칭 ★★★
- 경로 공유/내보내기 ★★
- 다중 목표 관리 ★★
- 사용자 인증 ★

## 구현 의존성 흐름

```
[목표 입력 + 랜덤]
      ↓
[Gemini 3경로 생성]
      ↓
[수직 맵 + 합류점]
      ↓
[분기점 클릭 + 하이라이트]
      ↓
[경로 애니메이션] ← [기간 전환] ← [노드 상세]
      ↓
[성취의 정원] ← [난이도 표시]
      ↓
[로컬 저장] ← [고스트 & 이벤트카드]
```

**원칙**: 어느 시점에서 멈추더라도 그 위까지는 완주 가능한 데모

## 6시간 타임라인

### Phase 1: 로켓 발사 (0:00~1:30, 1.5h)
- **0:00~0:20**: 프로젝트 세팅
  - Next.js + Tailwind + shadcn + React Flow
- **0:20~0:50**: Gemini 연동 + 프롬프트 v1
  - 합류점 포함 설계
- **0:50~1:30**: 목표 입력 화면 + 랜덤 버튼 + API 연결

**CP1 (1:30)**: "입력→Gemini→JSON 콘솔 출력" 확인 ✅

### Phase 2: 핵심 구현 (1:30~4:00, 2.5h)
- **1:30~3:00**: 수직 맵 시각화 + 합류점 노드 + 프롬프트 정교화
- **3:00~3:30**: 분기점 클릭 + 경로 하이라이트
- **3:30~4:00**: 기간 전환 (1년/3년/5년) + fade 애니메이션

**CP2 (4:00)**: "데모 시나리오 1회 완주" 확인 ✅

### Phase 3: 마무리 (4:00~5:00, 1h)
- **4:00~4:20**: 버그 수정 + 엣지 케이스
- **4:20~4:40**: UI 폴리시
- **4:40~5:00**: 데모 반복 3회 테스트

**CP3 (5:00)**: "데모 3회 연속 성공" 확인 ✅

### Phase 4: 발표 준비 (5:00~6:00, 1h) [코딩 금지]
- **5:00~5:15**: 발표 자료 정리 (3~5 슬라이드)
- **5:15~5:30**: 데모 대본 확정 + fallback 준비
- **5:30~5:50**: 리허설 2회
- **5:50~6:00**: 최종 점검

## 데모 시나리오 (3분)

### ACT 1: 시작 (30초)
**"누구나 시작할 수 있다"**
- 화면: 입력란 + 랜덤 버튼
- 🎲 클릭 → "풀스택 개발자 되기" 자동 채움 → 생성 클릭
- **감정**: 호기심

### ACT 2: 성장 (50초) ⭐
**"당신의 나무가 자랍니다"**
- 밑에서 줄기 올라옴 → 첫 분기점 → 세 갈래 가지
- 각 경로 노드 순차 생성
- 타임라인 1년→3년→5년 확장
- **감정**: 놀라움 → 기대감

### ACT 3: 합류 (30초) ⭐⭐
**"어떤 길이든 괜찮다" [감정적 클라이맥스]**
- 세 경로가 위쪽에서 합쳐짐 → 합류점 빛남
- "빠른 길이든, 깊이 파든, 모험하든 — 결국 여기서 만납니다"
- **감정**: 안도감 → 감동

### ACT 4: 마무리 (10초)
- "인생에 오답은 없습니다. LifePath가 모든 가능성을 보여드립니다."

## 아이디어 뱅크 추가 제안

### 데모 시나리오 임팩트 강화

- **"관객 참여형" 오프닝**: 데모 시작 시 "여기 계신 분 중 진로 고민해보신 분?" 질문 후, 관객에게 목표를 직접 말하게 하고 그 자리에서 입력. 사전 준비된 랜덤이 아닌 실시간 생성을 보여주면 기술력과 범용성을 동시에 증명. Plan B로 사전 캐싱 데이터 준비.

- **ACT 2에서 "일시정지" 연출**: 경로 애니메이션 중 의도적으로 한 번 멈추고, "지금 이 분기점에서 여러분이라면 어떤 길을 선택하시겠어요?" 관객에게 질문. 1~2초 침묵 후 클릭. 수동적 관람을 능동적 참여로 전환.

- **마지막 한 마디 강화**: ACT 4 마무리를 "인생에 오답은 없습니다"에서 한 단계 더 나가서, 합류점을 가리키며 "그리고 LifePath가 증명합니다 -- 어떤 길을 선택해도, 우리는 결국 만납니다." 합류점이라는 기술 구현과 감성 메시지의 연결.

### 발표 전략

- **"Before/After" 슬라이드 추가**: 문제 정의 슬라이드에서 기존 도구(엑셀 계획표, 직선형 로드맵)의 스크린샷과 LifePath의 나무형 맵을 나란히 비교. 시각적 대비로 차별화를 한눈에 전달.

- **"숫자로 말하기" 전략**: 발표 중 "6시간 동안 Gemini가 생성한 경로 노드 수: XX개, 합류점: XX개, 가능한 인생 시나리오: XX가지" 같은 구체적 숫자를 언급. 해커톤에서 숫자는 기술적 완성도의 증거.

- **비전 슬라이드에 "1년 로드맵" 시각화**: Tier 4 기능들을 타임라인에 배치한 간단한 로드맵 이미지. "오늘 만든 것은 시작일 뿐"이라는 메시지로 프로젝트의 확장 가능성을 보여줌. Canva/Figma로 5분 안에 제작 가능.

### 리스크 완화

- **"Golden Path" 사전 녹화**: 가장 이상적인 데모 흐름을 사전에 1회 화면 녹화해 둠. Plan C(영상 백업)가 아닌, 라이브 데모 도중 특정 구간이 불안정할 때 "잠깐, 이 부분을 좀 더 자세히 보여드리겠습니다"라며 자연스럽게 전환하는 Plan B+.

- **프리셋 목표 "데모 최적화 세트"**: 랜덤 프리셋 중 데모에서 가장 보기 좋은 결과를 만드는 목표 3~5개를 사전 테스트로 선별. 랜덤 버튼이 이 세트 안에서만 돌도록 데모 모드 플래그 추가. 구현 1줄(배열 필터링)로 데모 안정성 대폭 향상.

- **네트워크 불안정 대비 "오프라인 퍼스트" 전략**: 데모 장소 Wi-Fi가 불안정할 경우를 대비해, 핵심 데모 시나리오 2~3개의 Gemini 응답을 localStorage에 미리 캐싱하는 스크립트 준비. `USE_MOCK=true`보다 자연스러운 전환 가능.
