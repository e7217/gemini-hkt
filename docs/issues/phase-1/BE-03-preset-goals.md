- **Phase**: Phase 1 (로켓 발사)
- **담당**: backend-dev
- **예상 시간**: 15m
- **난이도**: 낮음
- **상태**: done

## 의존성
- **선행 작업**: [BE-01] 프로젝트 초기 세팅
- **후행 작업**: [FE-01] 목표 입력 화면 UI

## 구현 범위
1. 카테고리별 프리셋 목표 30~50개 상수 파일 생성
2. **카테고리**:
   - 커리어 (예: "풀스택 개발자 되기", "스타트업 창업하기")
   - 건강 (예: "마라톤 완주하기", "체중 10kg 감량")
   - 재무 (예: "1억 모으기", "부동산 투자 시작하기")
   - 관계 (예: "외국어로 원어민과 대화하기")
   - 취미 (예: "기타 연주 마스터하기", "유튜브 크리에이터 되기")
   - 자기개발 (예: "독서 100권 달성하기", "명상 습관 만들기")
3. 각 프리셋 데이터 구조:
   ```typescript
   { id: string, category: string, title: string, description: string }
   ```
4. 랜덤 선택 유틸 함수: `getRandomGoal()` → 전체에서 1개 랜덤 반환
5. 데모용 추천 프리셋 포함 ("풀스택 개발자 되기" 등 데모 시나리오 대응)

- 데모 시나리오에서 "풀스택 개발자 되기"가 등장하므로 해당 프리셋은 반드시 포함
- 랜덤 목표가 너무 생소하면 데모 임팩트가 떨어지므로, 보편적이고 공감 가능한 목표 위주로 구성
- 카테고리별 최소 5개 이상 확보하여 랜덤 선택 시 다양성 보장

## 아이디어 뱅크 제안

- **세대별 경로 프리셋 추가**: 기존 카테고리 외에 "Z세대 인기 목표", "30대 전환기 목표", "시니어 도전 목표" 같은 세대별 카테고리를 추가하면 "모든 세대를 위한 도구"라는 사회적 임팩트 포지셔닝 강화. 각 세대별 3~5개면 충분.

- **데모 최적화 프리셋 세트**: 랜덤 프리셋 중 데모에서 가장 보기 좋은 결과를 만드는 목표 3~5개를 사전 테스트로 선별하고, 데모 모드 플래그(`DEMO_MODE=true`)일 때 이 세트 안에서만 랜덤 선택하도록 구현. 배열 필터링 1줄로 데모 안정성 대폭 향상.

- **페르소나 기반 프리셋**: "김서연(24세, 졸업 예정)처럼 시작하기" / "이준호(29세, 직장인 3년차)처럼 시작하기" 같은 프리셋을 추가하면 유저 페르소나를 실제 UX에 녹여서 공감대 형성. 프리셋 데이터에 `persona` 필드만 추가하면 됨.
