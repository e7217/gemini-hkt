## 구현 범위
1. **목표 텍스트 입력 필드** (B-1):
   - 자유 텍스트 입력
   - 플레이스홀더: "이루고 싶은 목표를 입력하세요"
   - shadcn/ui Input 컴포넌트 활용
2. **"경로 생성하기" 버튼** (B-2):
   - POST /api/paths/simulate API 호출 연결
   - 로딩 중 비활성화
   - shadcn/ui Button 컴포넌트 활용
3. **로딩 상태 UI** (B-3):
   - API 호출 중 스피너 또는 로딩 텍스트 표시
   - 버튼 로딩 상태 전환
4. **랜덤 목표 버튼 🎲** (B-4):
   - 클릭 시 프리셋(BE-03)에서 랜덤 선택
   - 입력란 자동 채움
   - 데모 시나리오: 🎲 클릭 → "풀스택 개발자 되기" 자동 채움
5. **Zustand 스토어 설정**:
   - 목표 텍스트 상태 (goal)
   - 로딩 상태 (isLoading)
   - 경로 데이터 (pathMap: PathMap | null)
   - 에러 상태 (error)
6. **페이지 레이아웃**:
   - 중앙 정렬
   - 다크 테마 배경

## 아이디어 뱅크 제안

- **플레이스홀더 롤링**: 입력 필드의 placeholder가 3초마다 바뀌면서 다양한 목표 예시를 보여줌. "풀스택 개발자 되기...", "카페 창업하기...", "유튜버 도전하기...". `setInterval` + 페이드 전환으로 구현. 빈 화면의 지루함을 없애고 영감 제공.

- **페르소나 기반 프리셋 버튼**: 랜덤 버튼 옆에 "김서연처럼 시작하기" / "이준호처럼 시작하기" 같은 작은 태그 버튼 배치. 클릭 시 해당 페르소나의 고민이 자동 입력. 유저 페르소나를 실제 UX에 녹여서 공감대 형성.

- **"30초 온보딩" 스플래시**: 첫 화면 로드 시 3초짜리 미니 애니메이션으로 "목표 입력 -> 나무 성장 -> 합류점 빛남"을 미리 보여주는 티저. 사용자가 무엇을 기대할 수 있는지 즉시 이해. Lottie 파일 하나 또는 CSS 애니메이션으로 구현 가능.

- **음성 입력 버튼**: 마이크 아이콘 버튼을 추가하여 Web Speech API로 음성을 텍스트로 변환 후 입력란에 채움. 데모에서 "풀스택 개발자가 되고 싶어요"라고 말하는 장면은 강렬한 인상. `window.SpeechRecognition` API 몇 줄로 구현 가능.
