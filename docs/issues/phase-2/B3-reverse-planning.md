# Issue: 역방향 플래닝 (B3)

## 1. 개요
- **분류**: 필수 (Must-have) - 경로 생성 AI
- **설명**: 목표에서 현재로 역추적, Gemini 역순 단계 분해
- **목적**: 사용자가 달성하고자 하는 최종 목표를 먼저 설정하고, 이를 이루기 위해 필요한 단계들을 현재 시점으로 역산하여 현실적인 계획을 제공합니다.

## 2. 주요 기능
- 최종 목표 입력 시 Gemini API를 활용하여 거꾸로 내려오는 단계별 마일스톤 생성.
- 현재 사용자의 상태/위치에서 출발하는 기존 순방향 생성과 결합 또는 선택 가능.

## 3. 구현 고려사항
- 프롬프트 엔지니어링: Gemini에게 '목표 달성을 위한 선행 조건들을 역순으로 추적해달라'는 지시 필요.
- UI 표현: 트리 구조에서 목표(최상단)로부터 뿌리(현재)로 내려오는 시각적 피드백.
