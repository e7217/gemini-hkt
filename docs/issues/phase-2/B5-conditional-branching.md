# Issue: 조건부 분기 (B5)

## 1. 개요
- **분류**: 필수 (Must-have) - 경로 생성 AI
- **설명**: "만약 이 자격증을 취득하면" 같은 조건 기반 추가 분기 생성
- **목적**: 특정 마일스톤의 달성 여부나 선택에 따라 이후의 경로가 어떻게 달라지는지 동적으로 보여주어, 사용자가 선택의 중요성을 체감하게 합니다.

## 2. 주요 기능
- 경로 상의 특정 노드에서 '만약 ~한다면' (What-if) 시나리오 설정 기능.
- 해당 조건이 충족되었을 때 파생되는 새로운 가지(Sub-path)를 실시간으로 맵에 추가.

## 3. 구현 고려사항
- 기존에 생성된 맵 데이터 구조(JSON/Graph)에 동적으로 노드와 엣지를 주입하는 로직.
- 조건 입력용 간편 UI (예: 노드 클릭 후 '조건부 분기 추가' 버튼).
