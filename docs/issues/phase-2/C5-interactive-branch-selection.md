# Issue: 분기점 인터랙티브 선택 (C5)

## 1. 개요
- **분류**: 필수 (Must-have) - 시각화 & 인터랙션
- **설명**: 분기점에서 직접 경로 선택, 실시간 미래 지도 변화
- **목적**: 사용자가 단순히 경로를 구경하는 것에 그치지 않고, 갈림길에서 자신의 선택을 반영하여 미래의 경로 변화를 실시간으로 확인하게 함으로써 몰입감을 극대화합니다.

## 2. 주요 기능
- 갈림길(분기점) 노드 도달/선택 시, 가능한 선택지 UI 노출.
- 특정 옵션을 클릭하면, 선택되지 않은 다른 가지들은 흐려지거나 사라지고, 선택한 경로를 중심으로 지도가 재정렬/확장됨.

## 3. 구현 고려사항
- React Flow의 상태 관리 업데이트와 애니메이션 전환 효과.
- 사용자의 선택 내역(히스토리) 추적 및 되돌리기 기능 필요성 검토.
