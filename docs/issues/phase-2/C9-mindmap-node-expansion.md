# Issue: 마인드맵 노드 확장 (C9)

## 1. 개요
- **분류**: 필수 (Must-have) - 시각화 & 인터랙션
- **설명**: 노드 클릭 시 마인드맵처럼 새로운 방향의 분기 경로를 실시간 또는 사전 생성하여 표시
- **목적**: 사용자가 특정 노드(단계)에 대해 더 깊이 탐구하고 싶을 때, 해당 노드를 중심으로 파생되는 상세 액션 플랜이나 대안을 시각적으로 확장하여 보여줍니다.

## 2. 주요 기능
- 특정 노드(예: '자격증 취득')를 클릭하면 하위 노드들이 방사형이나 트리 형태로 확장되는 UI.
- 확장되는 노드의 내용은 사전에 생성된 데이터이거나, 클릭 시점에 Gemini API를 호출하여 동적으로 생성.

## 3. 구현 고려사항
- React Flow를 활용한 노드 동적 추가 및 레이아웃 재계산 (Dagre 등 레이아웃 엔진 활용).
- 실시간 생성 시 API 응답 대기 시간 동안의 로딩(Skeleton/Spinner) 처리.
