# Issue: 시간의 가격표 (기회비용) (F1)

## 1. 개요
- **분류**: 필수 (Must-have) - AI 고급 기능
- **설명**: 노드별 소요 시간 및 기회비용 표시
- **목적**: 단순히 '무엇을 해야 하는가'를 넘어, 각 단계를 선택했을 때 소모되는 시간과 포기해야 하는 가치(기회비용)를 명시하여 더 현실적이고 신중한 목표 설정을 돕습니다.

## 2. 주요 기능
- 경로 생성 시 Gemini가 각 노드(마일스톤)에 예상 소요 시간과 잠재적 기회비용을 데이터로 포함.
- 노드 위 또는 툴팁/상세 패널에 이 정보(예: "소요 기간: 6개월, 기회비용: 단기 소득 창출 기회 감소")를 시각적으로 표시.

## 3. 구현 고려사항
- 프롬프트 설계 시 기회비용을 추론할 수 있는 맥락 제공.
- 맵 렌더링 시 정보량이 너무 많아지지 않도록 UI를 적절히 숨기거나 아이콘화하여 제공.
