# Issue: 경로 성공 확률 (F4)

## 1. 개요
- **분류**: 필수 (Must-have) - AI 고급 기능
- **설명**: 경로별 예상 난이도 및 성공 확률 AI 추정
- **목적**: Fast Track, Deep Dive 등 각 경로가 현실적으로 얼마나 달성 가능한지를 AI가 분석한 수치(확률/난이도)로 제공하여 사용자의 의사결정을 돕습니다.

## 2. 주요 기능
- 전체 경로 생성 시, 각 경로의 총 예상 기간, 요구되는 리소스, 일반적인 실패 요인을 종합하여 '성공 확률(%)' 또는 '난이도(상/중/하)'를 산출.
- 경로 선택 화면이나 비교 뷰에서 해당 수치를 직관적으로 표시 (예: "성공 확률 85%, 난이도: 높음").

## 3. 구현 고려사항
- Gemini의 할루시네이션(환각)을 방지하고 그럴듯한 근거(예: "요구되는 스킬이 많아 시간 투자가 큼")와 함께 확률을 제시하도록 프롬프트 세부 조정.
- UI 디자인 시 확률 수치가 사용자에게 시각적으로 명확하게 전달되도록 컴포넌트 설계.
