## 의존성

- **후행 작업**: [FE-07] 버그 수정 + UI 폴리시

## 구현 범위
1. **노드 클릭 → 상세 패널 표시** (D-1):
   - 노드 클릭 이벤트 핸들링
   - 선택된 노드 정보를 상세 패널에 표시
   - 패널 열기/닫기 전환
2. **우측 사이드 패널** (F-1):
   - 화면 우측 30% 너비
   - 오버레이 또는 맵 영역 축소 방식
3. **패널 콘텐츠**:
   - 스텝 이름 + 설명 (F-2)
   - 예상 기간 + 난이도 표시 (F-3)
   - 현재 트랙 정보 (F-4) - 트랙명 + 색상 배지
   - tips 목록 표시
4. **트랙 선택 하이라이트** (D-2):
   - 선택한 트랙의 노드/엣지 밝게
   - 나머지 트랙 dimmed 처리 (opacity 0.3 등)
5. **트랙 범례/레전드** (D-3):
   - Fast Track(금), Deep Dive(파랑), Risk(보라) 표시
   - 클릭으로 트랙 선택/해제
   - 맵 상단 또는 좌측에 배치
6. **Zustand 스토어 확장**:
   - selectedNode: PathNode | null
   - selectedTrack: string | null
   - isPanelOpen: boolean

## 기술 검토 노트
- 상세 패널은 데모에서 "노드 클릭 → 구체적 정보 확인"이라는 인터랙션을 보여주는 핵심 요소
- dimmed 처리는 React Flow 노드/엣지의 style 속성으로 opacity 조절
- 패널 열림/닫힘 트랜지션은 CSS transition으로 구현 (translate-x 또는 width 애니메이션)
- 합류점 노드 클릭 시에는 connectedPaths 정보 + message를 별도로 표시

## 아이디어 뱅크 제안

- **"첫 걸음" 하이라이트**: 각 경로의 첫 번째 노드를 상세 패널에서 특별히 강조하고, "오늘 당장 할 수 있는 것"이라는 라벨 부여. `actionItem` 필드가 있다면 함께 표시. 실행력을 높이는 넛지.

- **Gemini 실시간 응원 코치**: 상세 패널에 "AI 한마디" 영역을 추가하여, 해당 단계에 맞는 응원 메시지를 표시. 데이터에 이미 포함된 tips를 활용하되, 첫 번째 tip을 하이라이트 스타일로 강조 표시하면 별도 API 호출 없이 코치 느낌 구현 가능.

- **노드 롱프레스 퀵 프리뷰**: 모바일 감성의 롱프레스 인터랙션으로, 노드를 길게 누르면 사이드 패널 대신 작은 플로팅 카드로 핵심 정보(제목+기간+난이도)만 표시. `onMouseDown` + 타이머 300ms로 간단 구현. 빠르게 훑어볼 때 유용.

- **합류점 감성 메시지 특별 표시**: 합류점 노드 클릭 시 message를 일반 텍스트가 아닌, 큰 따옴표 + 이탤릭 + 특별 색상으로 강조 표시. 데모에서 합류점을 클릭했을 때 감동 메시지가 눈에 띄게 표시됨.
