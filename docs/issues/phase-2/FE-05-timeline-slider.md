   - 슬라이더 입력 디바운스 150~200ms

## 기술 검토 노트
- **디바운스 필수**: 슬라이더 드래그 중 매 프레임마다 dagre 재계산하면 성능 저하 심각. 150~200ms 디바운스 반드시 적용
- **엣지 끊김 처리**: 중간 노드가 필터링으로 숨겨질 때, 해당 노드에 연결된 엣지도 함께 숨겨야 함. 남은 노드 간 새로운 엣지를 만들거나, 필터링된 노드의 엣지를 hidden 처리하는 방식 중 선택 필요
- **피벗 기준**: 3:30 시점에 슬라이더 구현이 어려우면 버튼 3개(1년/3년/5년)로 대체. 버튼 방식도 데모에서 효과적으로 전달 가능
- 데모 시나리오 ACT 2에서 "타임라인 1년→3년→5년 확장"이 핵심 인터랙션

## 아이디어 뱅크 제안

- **노드 등장 시 사운드 피드백**: 슬라이더를 드래그하여 새 노드가 등장할 때 작은 "팅" 소리를 재생. `new Audio('ting.mp3').play()` 한 줄로 구현. 시각 + 청각 자극으로 나무 성장의 몰입도를 크게 높일 수 있음. 사운드 파일 1개만 준비하면 됨.

- **슬라이더 위 "현재 시점" 라벨**: 슬라이더 thumb 위에 "현재: 2년 3개월" 같은 동적 라벨을 표시. CSS `::after` pseudo-element 또는 작은 floating div로 구현. 사용자가 정확히 어느 시점을 보고 있는지 직관적으로 파악 가능.

- **"자동 재생" 버튼**: 슬라이더 옆에 재생 버튼을 추가하여, 클릭하면 1년부터 5년까지 자동으로 슬라이더가 이동하며 나무가 자라나는 애니메이션을 보여줌. `setInterval`로 슬라이더 값을 점진적으로 증가. 데모에서 손을 떼고 "보세요, 나무가 자랍니다"라고 말할 수 있는 순간 연출.
