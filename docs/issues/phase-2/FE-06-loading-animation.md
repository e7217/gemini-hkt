## 기술 검토 노트
- Gemini API 응답 시간이 2~5초 정도 걸릴 수 있으므로, 로딩 화면이 지루하지 않아야 함
- 너무 복잡한 애니메이션보다는 깔끔한 스피너 + 텍스트 메시지가 해커톤에서 더 안정적
- 로딩 중 "경로를 탐색 중..." → "분기점을 찾는 중..." → "합류점을 연결하는 중..." 같은 단계별 텍스트 변화도 효과적
- 난이도가 낮고 독립적이므로 다른 FE 작업과 병렬 진행 가능

## 아이디어 뱅크 제안

- **"스켈레톤 로딩" 맵**: 로딩 중 단순 스피너 대신, React Flow 캔버스에 회색 스켈레톤 노드들이 나무 형태로 미리 배치되어 있다가, 실제 데이터가 오면 하나씩 색이 채워지는 효과. 로딩 시간이 오히려 연출의 일부가 됨. 스켈레톤 데이터는 고정된 더미 노드 5~6개로 간단 구현.

- **단계별 진행 텍스트 강화**: "경로를 탐색 중..." -> "분기점을 찾는 중..." -> "합류점을 연결하는 중..." -> "나무를 심는 중..." 같은 단계별 텍스트에 각 문구에 어울리는 이모지를 추가. `setInterval`로 2초마다 전환. 대기 시간을 스토리텔링으로 변환.

- **로딩 중 미니 나무 성장 애니메이션**: 단순 스피너 대신, 작은 나무 실루엣이 CSS `@keyframes`로 점점 자라나는 애니메이션. `height`와 `opacity`만 변화시키면 되므로 15줄 이내 CSS로 구현 가능. 서비스의 핵심 메타포(나무 성장)를 로딩 화면에서도 일관되게 전달.
