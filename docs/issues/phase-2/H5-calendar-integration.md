# Issue: 캘린더 연동 (H5)

## 1. 개요
- **분류**: 필수 (Must-have) - 데이터 & 저장
- **설명**: 구글 캘린더 등에 각 노드(마일스톤)의 예상 일정 자동 등록
- **목적**: 사용자가 AI가 생성해준 인생 경로를 눈으로만 확인하는 것에 그치지 않고, 실제 자신의 스케줄러와 동기화하여 실천 가능성과 실행력을 극대화합니다.

## 2. 주요 기능
- 사용자가 특정 경로를 최종 선택하면, 해당 경로의 노드(단계)별 예상 시점을 계산.
- 구글 캘린더 API(또는 iCal 다운로드)를 연동하여 사용자의 캘린더에 일정 및 마일스톤 이벤트 생성.
- 이벤트 상세 내용에는 목표, 필요한 작업, 예상 소요 시간 및 LifePath 링크 포함.

## 3. 구현 고려사항
- Google Calendar API OAuth 2.0 인증 절차 및 권한(스코프) 설정.
- 상대적 시간(예: "3개월 후")을 사용자의 현재 시점 기준 절대적 날짜로 변환하는 날짜 계산 로직.
- 향후 사용자가 경로를 수정하거나 다시 생성할 때 기존 일정을 덮어쓰거나 관리하는 방안.
