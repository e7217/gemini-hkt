## 구현 범위
1. **엣지 케이스 처리**:
   - 빈 입력 방지 (유효성 검증)
   - API 에러 시 사용자 친화적 메시지 ("다시 시도해 주세요")
   - 긴 목표 텍스트 처리 (말줄임 또는 최대 길이 제한)
   - 노드가 없는 경로 처리
   - 합류점 없는 경로 데이터 대응
2. **UI 폴리시**:
   - 간격/정렬 미세 조정
   - 호버 효과 보강 (노드, 버튼)
   - 트랜지션 부드럽게 조정
   - 폰트 크기/굵기 일관성 확인
   - 색상 대비 확인 (다크 테마 가독성)
3. **반응성 확인**:
   - 데스크탑 1280px+ 레이아웃 정상 확인
   - 맵 영역 + 패널 영역 비율 확인
4. **데모 시나리오 흐름 검증**:
   - 🎲 클릭 → 목표 자동 채움 → 생성 → 맵 표시 → 노드 클릭 → 타임라인 전환
   - 전체 흐름이 끊김 없이 자연스러운지 확인

## 아이디어 뱅크 제안

- **키보드 숏컷 네비게이션**: `1`, `2`, `3` 키로 Fast/Deep/Risk 경로 전환, `Escape`로 패널 닫기. 데모 시 마우스 없이 키보드만으로 빠르게 전환하면 전문성 어필. `useEffect` + `addEventListener('keydown')` 몇 줄로 구현.

- **호버 효과 일관성 강화**: 모든 인터랙티브 요소에 통일된 `transition: all 0.2s ease` 적용. 특히 노드 호버 시 글로우가 살짝 강해지고 scale이 1.02로 커지는 효과. CSS 2줄로 전체 인터랙션 품질이 한 단계 올라감.

- **"다크 우주" 배경 별 파티클**: 폴리시 단계에서 시간이 남는다면, 배경에 미세한 별 반짝임을 추가하는 것만으로 비주얼 완성도가 크게 올라감. CSS `@keyframes twinkle` + 50개 작은 점. 구현 10분 이내.
