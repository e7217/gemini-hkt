# Data Model: BE-01 프로젝트 초기 세팅

**Branch**: `001-project-setup` | **Date**: 2026-02-27

## Overview

This feature does not introduce runtime data models (no database, no API). It establishes the **configuration and structural model** for the entire LifePath project. The "data" in this context is project configuration, directory structure, and the foundational TypeScript type scaffold.

## 3. Zustand Store Scaffold (store/usePathStore.ts)

```typescript
// store/usePathStore.ts — initial scaffold
'use client';

import { create } from 'zustand';
import type { PathMap, PathId } from '@/types';

interface PathStore {
  // Goal input state
  goal: string;
  setGoal: (goal: string) => void;

  // Path data (populated after API call)
  pathMap: PathMap | null;
  setPathMap: (pathMap: PathMap | null) => void;

  // UI state
  selectedTrack: PathId | null;
  setSelectedTrack: (track: PathId | null) => void;
  timelineMonths: number;
  setTimelineMonths: (months: number) => void;

  // Loading state
  isLoading: boolean;
  setIsLoading: (loading: boolean) => void;

  // Reset
  reset: () => void;
}

export const usePathStore = create<PathStore>()((set) => ({
  goal: '',
  setGoal: (goal) => set({ goal }),
  pathMap: null,
  setPathMap: (pathMap) => set({ pathMap }),
  selectedTrack: null,
  setSelectedTrack: (selectedTrack) => set({ selectedTrack }),
  timelineMonths: 36, // default: 3 years
  setTimelineMonths: (timelineMonths) => set({ timelineMonths }),
  isLoading: false,
  setIsLoading: (isLoading) => set({ isLoading }),
  reset: () => set({
    goal: '', pathMap: null, selectedTrack: null,
    timelineMonths: 36, isLoading: false,
  }),
}));
```

## 4. Environment Variable Model

| Variable | Required | Location | Description |
|----------|----------|----------|-------------|
| `GEMINI_API_KEY` | Yes (production) | `.env.local` (server only) | Google Gemini API key for path generation |
| `USE_MOCK` | No | `.env.local` | Set to `true` to use mock data instead of Gemini API |
| `NEXT_PUBLIC_*` | None in this phase | — | No client-side env vars in this feature |

**Security constraint**: All environment variables used by Gemini API calls must be server-side only (no `NEXT_PUBLIC_` prefix). This is enforced by the Next.js App Router architecture where API routes execute server-side.
