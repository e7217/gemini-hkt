# Feature Specification: B3 Reverse Planning
**Feature Branch**: `018-b3-gemini`
**Status**: Draft
**Input**: Issue docs/issues/phase-2/B3-reverse-planning.md

## User Story 1 - Reverse Planning (Priority: P1)
As a user, I want to input my final goal and see the steps working backward to my current state, so I can establish a realistic starting point.

## Functional Requirements
- FR-001: Support reverse path generation prompt for Gemini API.
- FR-002: Add 'Reverse Planning' toggle to GoalInput UI.
- FR-003: Render backward progression visually in the map.
