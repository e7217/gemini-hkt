# Feature Specification: F1 Opportunity Cost
**Feature Branch**: `022-f1`
**Status**: Draft
**Input**: Issue docs/issues/phase-2/F1-opportunity-cost.md

## User Story 1 - Opportunity Cost Display (Priority: P1)
As a user, I want to see the estimated time and opportunity cost for each milestone, so I can make informed decisions about trade-offs.

## Functional Requirements
- FR-001: Gemini API must generate time estimates and a 1-sentence opportunity cost for each node.
- FR-002: Nodes and the Detail Panel must display the opportunity cost data clearly.
