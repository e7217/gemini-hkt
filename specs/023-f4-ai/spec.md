# Feature Specification: F4 Path Success Probability
**Feature Branch**: `023-f4-ai`
**Status**: Draft
**Input**: Issue docs/issues/phase-2/F4-path-success-probability.md

## User Story 1 - Success Probability (Priority: P1)
As a user, I want to see an AI-estimated success probability and difficulty level for the overall paths so I know what to expect.

## Functional Requirements
- FR-001: The Gemini API should estimate success probability (%) and difficulty (Low/Medium/High) per track.
- FR-002: The UI should display these metrics in the track legend and path selection views.
